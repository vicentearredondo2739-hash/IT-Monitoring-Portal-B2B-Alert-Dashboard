# IT-Monitoring-Portal-B2B-Alert-Dashboard
> Real-time infrastructure alert reporting system built for multi-tenant B2B monitoring environments.
>
- Multi-company alert management
- Drag & drop TXT file parsing (Centreon export format)
- Chunked upload for large files (>6MB)
- Interactive dashboard: donut charts, TOP 10, drill-down
- Export to PDF and Excel
- Math CAPTCHA login system
- Report merge/append logic

Frontend: Vanilla JS · Tailwind CSS · Chart.js · IndexedDB  
Backend: PHP 5.6+ · MySQL  
Libraries: html2pdf.js · ExcelJS
